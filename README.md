# E-commerce Sales Analysis

## About the project
This is a **practice Data Analyst project** built using a synthetic e-commerce sales dataset. It demonstrates data cleaning, exploratory data analysis, SQL querying, KPI calculation, and business insights.

> The dataset is synthetic and created for portfolio/practice purposes. It should not be presented as real company data.

## Tools
- Python
- Pandas
- NumPy
- Matplotlib
- SQL
- CSV

## Files
- `ecommerce_sales.csv` — synthetic sales dataset
- `analysis.py` — Python analysis
- `analysis_queries.sql` — SQL practice queries

## Questions answered
1. What are total sales, cost and profit?
2. Which categories generate the most sales?
3. Which products are top performers?
4. Which regions perform best?
5. How do sales change month by month?
6. Which sales channel performs best?
7. What is the average order value?
8. What is the overall and category-level profit margin?

## Key learning outcomes
- Loading and inspecting a dataset
- Checking missing values
- Grouping and aggregating data
- Creating business KPIs
- Trend analysis
- SQL aggregation and filtering
- Communicating findings in business terms

## How to run
```bash
pip install pandas numpy matplotlib
python analysis.py
```
